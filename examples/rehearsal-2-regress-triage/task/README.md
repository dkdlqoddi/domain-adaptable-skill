# 과제: 회귀 결과 정리 도우미

SoC 검증팀은 매일 밤 회귀 테스트를 돌리고, 아침마다 그 결과를 정리해 팀에 공유합니다.
이 아침 정리가 너무 오래 걸린다는 이야기가 계속 나옵니다.
검증팀 담당자와 이야기해서, 아침 정리를 도와주는 도구를 만들어 주세요.
지난밤과 그 전날 밤 결과 일부를 `samples/`에 넣어 두었습니다.

## 사용법
1. 설치: 없음. Python 3.6+ 표준 라이브러리만 씁니다. `regsum.py` 하나를 서버에 둡니다.
2. 실행: `python3 regsum.py <회귀 날짜 폴더> <보관 폴더>` — 예) `python3 regsum.py /proj/soc/regress/2026-10-25 <공유 보관 폴더>`.
   표준출력 = 채널에 붙여 넣을 글(끊긴 로그 → 새로 생긴 실패 → 계속 남은 실패). 보관 폴더에 `<날짜>.tsv`가 남아 다음 날 비교 기준이 됩니다. 대리자도 **같은 보관 폴더**를 씁니다.
   4000바이트가 넘는 날은 `---------- 여기서 나눠 올림 ----------` 줄 사이를 메시지 하나씩 올립니다.
3. 확인: `python3 -m unittest -q test_regsum && bash fixtures/check.sh` → 모두 `PASS`.
   직접 보기: `h=$(mktemp -d); python3 regsum.py samples/2026-10-24 $h >/dev/null; python3 regsum.py samples/2026-10-25 $h`
