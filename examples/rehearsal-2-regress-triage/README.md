| 항목 | 결과 |
|---|---|
| 웹이 아닌 과제 | 됐다. 하네스가 CLI 하나, 모듈 1개를 골랐고 계약은 CLI·파일 형식으로 썼다 |

## 병렬 위임 시험 (별도 프로젝트, 고친 규칙 확인)
독립된 두 폴더(`wc/`, `words/`)에 슬라이스 S1·S2를 두고 `/delegate S1 --parallel`을 돌렸습니다.
- 루트가 S2를 스스로 골라 브리프 2개를 만들고, 승인 뒤 두 에이전트를 함께 띄웠다.
- **모든 보고가 온 뒤** 둘 다 검증 명령을 다시 돌렸고, 범위 확인은 두 범위를 합쳐서 해 상대 파일을 되돌리지 않았다.
- 커밋이 슬라이스별로 나뉘었다: S1 = `wc/` + TASKS + `briefs/S1.md`, S2 = `words/` + TASKS + `briefs/S2.md` + DECISIONS.
- S2 에이전트가 브리프에 없던 테스트 파일을 넣자 루트가 잡아서 남길지 물었고, 결정을 D-001로 기록했다.

## 비용과 토큰
`costs.md`에 세션별 표가 있습니다. 하네스 약 **$14.74**(세션 실행 시간 합 51분), 페르소나 약 $0.13, 병렬 시험 약 $0.85.
- 호출 한 번의 기본 맥락이 약 2만 토큰(시스템 프롬프트·도구·CLAUDE.md·스킬 본문)입니다. 그래서 짧은 명령도 $0.1 안팎이 듭니다.
- 가장 비싼 것은 위임 세션(각 $0.7~1.2)과 `/spec`($1.2~1.4)입니다. 서브에이전트 토큰이 위임 세션에 합쳐집니다.
- 주의: `--resume`으로 이어 간 세션의 비용·토큰은 **세션 누적값**입니다. 호출마다 더하면 두 번 셉니다.

## 확인하지 못한 것
- 담당자 서버의 Python 3.6에서 실제로 돌려 보지 못했습니다(이 PC는 3.10, uv에 3.6 없음, WSL에 Docker 없음). 정적 분석(`uvx vermin`)으로는 최소 3.3이 필요하다고 나와 3.7 이상 기능은 없습니다.
- 사람이 직접 하는 리허설이 아닙니다. 사람 역할을 Claude가 했습니다.

## 직접 리허설하기 (사람이 하는 3차)
1. 빈 폴더에 `task/README.md`의 맨 위 다섯 줄만 `README.md`로 두고, `python3 kit/make_samples.py samples`로 샘플 로그를 만듭니다.
2. `git init` → 저장소의 `scripts/install.sh <새 과제 폴더>` → 초기 파일과 설치물을 검토해 첫 커밋 → `claude` → `/kickoff`. ZIP을 반입할 때는 현재 [설치 안내](../../README.md#준비와-설치-터미널)대로 임시 폴더에 풉니다.
3. 다른 AI 채팅(Gemini 등)의 첫 메시지로 `kit/persona.md`를 붙여 넣으면 담당자 역할을 합니다. **시트는 읽지 마세요.** 숨은 사실이 들어 있습니다.
4. 끝나면 이 폴더의 `docs/`, `transcripts/`와 비교해 보세요.
