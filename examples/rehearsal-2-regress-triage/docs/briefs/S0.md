- [ ] 출력 모양이 아래 "기대 출력"과 글자 단위로 같다

## 지켜야 할 계약 (샘플 값 그대로)
CLI:
```
python3 regsum.py <회귀 날짜 폴더> <보관 폴더>
```
- 회귀 날짜 = 회귀 날짜 폴더의 이름(`YYYY-MM-DD`). 끝에 `/`가 붙어 들어와도 같은 날짜로 읽을 것.
- 보관 폴더: 없으면 만든다.
- 출력·보관 파일은 로캘과 무관하게 UTF-8. Python 3.6 표준 라이브러리만 (3.7+ 기능 금지).

기대 출력 (비교 기준이 없을 때의 첫 줄, 세 칸 모두 비어 있음; 맨 끝 줄바꿈 1개):
```
회귀 2026-10-24 정리 (비교 기준: 없음, 전부 새로 생긴 실패로 표시)

[끊긴 로그 — LSF 시간 제한, 또는 아직 실행 중]
없음

[새로 생긴 실패]
없음

[계속 남은 실패]
없음
```
(칸 제목의 `—`는 U+2014 em dash. 칸 사이에 빈 줄 하나.)

보관 파일 `<보관 폴더>/2026-10-24.tsv` 내용 (탭 구분, UTF-8, 줄바꿈 `\n`, ⇥ = 탭 문자):
```
test⇥total⇥seeds⇥key
```
