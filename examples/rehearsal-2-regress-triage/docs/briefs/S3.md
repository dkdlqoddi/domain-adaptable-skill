| 경우 | 표준에러 | 종료코드 | 보관 |

| 폴더 이름이 `YYYY-MM-DD`가 아님 | `오류: 폴더 이름이 회귀 날짜(YYYY-MM-DD)가 아닙니다: <이름>` | 2 | 안 씀 |

## 다음은 정해진 것 (계약에 명시 없어 루트가 정함)
- 검사 순서는 표 순서를 따른다: 인자 수 → 폴더 존재 → 폴더 이름 → `.log` 0개 → (이름 경고) → 비교 기준 읽기·검사 → 보관 폴더 만들기·쓰기 → 출력.
- **오류 경로에서는 보관 폴더도 만들지 않는다** (사용자 결정). ④-a가 `ls $h`가 비어 있는지 확인한다.
- `N`은 머리 줄을 1로 세는 파일 줄 번호다. 빈 줄도 "열 4개 아님"으로 본다.
- 폴더 이름은 `^\d{4}-\d{2}-\d{2}$` 정규식으로만 본다. 달력상 유효한 날짜인지는 검사하지 않는다.
- `.log` 0개는 이름 모양과 상관없이 `*.log` 개수로 센다. 전부 이름이 틀리면 경고 후 칸 모두 `없음`으로 정상 출력한다.
- `<파일>`과 `<경로>`는 인자로 받은 경로를 그대로 이어 붙인 문자열이다(`os.path.join(인자, 이름)`). `<이름>`은 폴더 이름(basename)이다.
- 표준에러도 표준출력처럼 `sys.stderr.buffer`에 UTF-8로 쓴다(Python 3.6 C 로캘에서 한글이 깨지므로). 줄 끝에 `\n`.

## 현재 코드 (S2 결과, 이 위에 고친다)
- `collect()`의 `# shortcut: 이름 모양이 다른 로그는 조용히 건너뜀 ...` 자리를 경고로 바꾸고, shortcut 주석을 지운다.
- `read_history()`의 `# shortcut: 정상 파일만 가정 ...` 자리에 검사를 넣고, shortcut 주석을 지운다. 깨진 줄 번호를 넘기는 방법은 가장 단순한 것으로 한다(예: `ValueError(N)`을 `main`에서 잡기).
- `main`은 지금 `argv[1]`, `argv[2]`를 바로 쓴다. 이 앞에 검사를 넣는다. 지금 `os.makedirs`가 비교 기준 읽기 뒤에 있으니 순서를 지킨다.

## 하지 말 것
- S4(나눠 올리기)는 손대지 않는다.
- SPEC 비목표: 설정 파일, 옵션 플래그, 캐시, 재시도, 보관 결과 잠금, 백업, 외부 패키지, Python 3.7+ 전용 기능(`dataclasses` 등).
- argparse, logging, 클래스, `csv` 모듈, 사용자 정의 예외 클래스를 들이지 않는다. 남은 `.tmp`를 정리하는 코드도 넣지 않는다(실행자는 1명뿐이고 다음 실행 때 덮어쓴다).
- 계약을 바꾸지 않는다. 막히면 `docs/TASKS.md` BLOCKER 표에 적고 멈춘다.
- 테스트는 `unittest`로 작게, `read_history`만 다룬다: 머리 줄이 다르면 1, 열이 3개면 2, total이 `one`이면 해당 줄 번호, 정상 파일이면 dict. CLI 경로는 check.sh와 손 확인으로 본다.
