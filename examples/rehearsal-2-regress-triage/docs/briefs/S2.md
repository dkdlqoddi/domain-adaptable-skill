## 지켜야 할 계약 (샘플 값 그대로)
### 비교 기준 고르기 (CONTRACT D)
- 비교 기준 = 보관 폴더에서 이름이 `YYYY-MM-DD.tsv`이고 날짜가 이번 회귀 날짜보다 **앞선** 파일 중 가장 최근 것. 다른 파일(같은 날짜·뒤 날짜·다른 이름)은 무시.
- 비교 기준은 오늘 보관 파일을 쓰기 **전에** 고르고 읽는다. 같은 날짜로 다시 돌리면 오늘 파일은 덮어쓴다.
- 보관 파일: UTF-8 TSV, 첫 줄 머리 `test⇥total⇥seeds⇥key`(⇥ = 탭), 이후 실패 묶음당 한 줄, seeds는 `,` 구분.
- 깨진 보관 파일 검사(머리 줄·열 4개·숫자 여부 → 종료코드 2)는 **S3 몫**. 지금은 정상 파일만 가정하고 읽는 자리에 `shortcut:` 주석.

### 나누기 (CONTRACT C)
- 새로 생긴 실패 = 비교 기준에 (테스트 이름, 묶음 기준 줄)이 없는 묶음. 계속 남은 실패 = 있는 묶음. 비교 기준이 없으면 전부 새로 생긴 실패.
- 첫 줄: 비교 기준이 있으면 `회귀 2026-10-25 정리 (비교 기준: 2026-10-24 결과)`, 없으면 `회귀 <날짜> 정리 (비교 기준: 없음, 전부 새로 생긴 실패로 표시)`.
- 계속 남은 실패에서 실패 seed 수가 지난번(보관 행의 seeds 개수)과 다르면: `- <테스트>, seed <전체>개 중 <지난 n>개에서 <n>개로(<seed들>): <원문>`. 줄어든 경우도 같은 모양. `<전체>`는 이번 실행 값.
- 보관 파일에는 나누기와 무관하게 이번 묶음 전부를 쓴다(S1과 동일). 끊긴 로그는 비교하지 않는다(S1과 동일).
