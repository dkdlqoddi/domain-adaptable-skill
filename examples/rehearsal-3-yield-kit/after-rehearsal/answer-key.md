# 정답과 채점 포인트 (리허설이 끝난 뒤에 열 것)

## 숨은 사실 — 페르소나 시트에 있는 것
| 사실 | 어떻게 열리나 | 들어가야 할 곳 |
|---|---|---|
| 제품마다 목표 수율이 다르다(K4 92%, K8 85%). 목표보다 5%p 넘게 낮으면 "떨어짐" | 기준을 물어야 열린다 | SPEC 판정 규칙, 계약 샘플 |
| 재측정: 같은 웨이퍼가 테스트 결과에 두 번 → 나중에 잰 것만 | 샘플에서 중복을 보고 물으면 열린다 | 테스트 결과 읽기 규칙 |
| 재작업: 같은 공정이 이력에 두 번 → 마지막 설비만 | 샘플에서 중복을 보고 물으면 열린다 | 공정 이력 읽기 규칙 |
| 챔버 단위로 보여야 조치할 수 있다 | 단위를 묻거나, 설비 단위 출력을 보여 주면 열린다 | 출력 단위 |
| 개수가 아니라 비율 비교(지난주 실수의 교훈) | 고르는 방법을 묻거나, 개수 순위 출력을 보여 주면 열린다 | 순위 규칙 |
| 비목표: 설비 자동 정지·명령, 대시보드, 머신러닝 예측, 실시간 알림 | 성공 기준·범위를 물으면 열린다 | SPEC 비목표 |
| Python 3.9 + pandas, 새 패키지 불가, 인터넷 불가, 데이터 반출 금지 | 실행 환경을 물으면 열린다 | SPEC 제약 |

## 데이터 함정 — 샘플에 심어 둔 것
- `eds_results.csv`는 엑셀 내보내기처럼 첫 줄에 BOM이 있다. `utf-8`로 읽으면 첫 열 이름이 `﻿lot_id`가 되어 `lot_id`를 못 찾는다(`utf-8-sig`로 읽으면 된다).
- 재측정 3장(L2610A02-07, L2610A02-19, L2610B01-11): 첫 측정이 58~64%이고, 95분 뒤 다시 잰 값은 정상이다. 첫 측정을 쓰면 떨어진 웨이퍼가 21장이 아니라 24장이 된다.
- 재작업 4장(L2610A01-04, L2610A01-16, L2610A02-22, L2610B01-03): PHOTO-02 다음 PHOTO-01. 둘 다 세면 노광 설비 집계가 틀린다.
- 잡음 1장(L2610A01-21, 86.6%): 원인과 무관하게 낮다. 정답 계산의 "나머지 2%"가 이 한 장이다.
- 기준 하나(87%)로 전 제품을 판정하면 K8 로트 전체가 떨어짐으로 나온다(37장).

## 정답 (샘플 기준, `check_answer.py`)
- **1순위: S130_CVD, CVD-07 챔버 B** — 지난 20장 중 20장(100%) vs 나머지 2%
- 설비 단위로만 보면 CVD-07은 53%로 흐려진다(A 챔버는 정상).
- 개수로 순위를 매기면 모든 웨이퍼가 지나는 CMP-02가 1위가 된다. 지난주 실수와 같은 함정이다.
- PHOTO-02(37% vs 19%), ETCH-03 챔버 C(41% vs 24%)는 원인 웨이퍼와 우연히 겹친 약한 신호다.
