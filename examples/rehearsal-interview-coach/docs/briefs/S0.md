## 지켜야 할 계약 (샘플 값 그대로)

### C. 실행 명령
- `python3 api/server.py [--data <경로>]` — 기본 `data/records.json`(현재 작업 디렉터리 기준). **다른 옵션 없음.**
- 시작 순서: ① 인자 → ② 기록 파일 읽어 검증: 없음 = 정상(빈 상태) / JSON 파싱 오류·`version`≠1·`records`가 배열 아님 = **stderr에 경로를 포함한 한국어 한 문장 + exit 1**, 파일을 만들거나 덮어쓰지 않는다 → ③ `127.0.0.1:8765` 바인드(사용 중 = stderr 한 줄 + exit 1) → ④ stdout 첫 줄(`flush=True`) → ⑤ serve. Ctrl+C = 트레이스백 없이 exit 0.
- stdout 첫 줄(두 칸 띄움 포함, 경로는 `--data` 값 그대로):
  ```
  인터뷰 연습 기록 — http://localhost:8765  (기록 파일: data/records.json)
  ```
- 요청 로그는 `http.server` 기본 그대로 둔다(로깅 설정·포맷 변경 금지).
- 파일 읽기 함수 하나를 시작 검증과 요청 처리가 같이 쓴다. 서버 객체를 만드는 함수(포트 인자)와 `main()`을 분리해 테스트가 포트 0으로 띄울 수 있게 한다.

### B. API
- 모든 JSON 응답: `Content-Type: application/json; charset=utf-8`, `Content-Length` 포함, 한글 이스케이프 없음(`ensure_ascii=False`).
- `GET /`, `GET /<파일>` → `ui/` 안의 파일(`ui/index.html` 등). 없는 파일·`ui/` 밖 경로는 404. 권장: `http.server.SimpleHTTPRequestHandler`에 `directory=<ui 절대경로>` — 경로 탈출 차단·index.html·404가 표준 라이브러리로 해결된다. `/api/`로 시작하지 않는 GET은 그대로 `super().do_GET()`.
- `GET /api/players` → **요청마다** 기록 파일을 읽어 계산(캐시 없음). 기록이 있는 선수 이름, 가나다순(`sorted`), 중복 없음.
  ```
  200 {"players":["김민수","박지훈","이서준"]}
  ```
  파일 없음 → `200 {"players":[]}`
- `GET /api/compare?player=<이름>&date=<YYYY-MM-DD>` — **S0 스텁**(`# S0 stub — S1에서 교체` 주석, 파일 안 봄). 쿼리 `player`(URL 디코딩: `%EA%B9%80%EB%AF%BC%EC%88%98` = 김민수)에 따라:
  - `김민수` → `fixtures/compare.response.json` 파일 내용 그대로 200
  - `박지훈` → `fixtures/compare.today.response.json` 파일 내용 그대로 200
  - 그 외(`player` 없음·빈 값 포함) → `200 {"player":"<쿼리 값, 없으면 \"\">","date":"<쿼리 값, 없으면 서버의 오늘 YYYY-MM-DD>","today":null,"previous":[]}`
  - 400 검증·실제 계산은 하지 않는다(S1 범위).
- `PUT /api/records` — **S0 스텁**(`# S0 stub — S3에서 교체`). 본문은 Content-Length만큼 읽어서 버리고 `fixtures/record.put.response.json` 파일 내용 그대로 200. 검증·저장 없음(S3 범위).
- 그 외 `/api/*`의 404·405 JSON 형식은 S3 범위 — 지금은 정적 서빙으로 떨어져 404가 나면 충분.
- 스텁의 픽스처 경로: `api/server.py` 위치 기준 `../fixtures/`(`Path(__file__).resolve().parent.parent / "fixtures"`). `ui/` 경로도 같은 방식(`.../ui`).

### D. 기록 파일
```json
{ "version": 1, "records": [ <A절 기록>, ... ] }
```
A절 기록 샘플(`records` 배열 원소 하나):
```json
{
  "player": "김민수",
  "date": "2026-10-16",
  "items": { "key_message": "상", "avoid_negative": "상", "answer_length": "중" },
  "memo": "세 가지 모두 안정적. 다음엔 돌발 질문 추가"
}
```
`fixtures/records.sample.json` = 선수 3명·기록 8건(김민수 4, 이서준 2, 박지훈 2). 픽스처는 읽기 전용 — 테스트에서 쓰기가 필요하면 `tempfile`에 복사한다. 손상 파일은 절대 덮어쓰지 않는다.

### ui/index.html (한 장, 빌드·패키지 없음)
- `<!doctype html>`, `<html lang="ko">`, `<meta charset="utf-8">`, 제목 "인터뷰 연습 기록".
- `<label for="player">선수</label>` + `<select id="player">`: 페이지 로드 시 `fetch('/api/players')` → `players` 배열로 `<option>`(값=표시=이름)을 채운다. 빈 배열이면 빈 select.
- 화면 글자는 GLOSSARY 용어(선수). 비교 표·입력란·저장 버튼·빈 상태 문구·에러 표시는 만들지 않는다(S2·S4 범위). 외부 CSS/JS/CDN·프레임워크 없음. 인라인 `<style>`은 필요 최소.
