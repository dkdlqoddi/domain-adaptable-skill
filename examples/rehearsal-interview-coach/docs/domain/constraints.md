# 데이터·환경·제약

## 입력 데이터 (출처, 형식, 규모, 갱신 주기)
- 질문: 홍보팀이 엑셀로 관리하는 목록 약 30개. 코치가 그날 5개를 골라 세트를 만든다. (인터뷰 2회차) 목록을 도구에 넣는 방법(붙여 넣기·파일)과 질문을 기록에 남겨야 하는지는 미확인. 목록은 시즌 중 가끔 바뀔 수 있다. (가정)
- 답변: 코치가 받아 적은 텍스트. 녹음도 하지만 거의 듣지 않으므로 텍스트가 주 입력. (인터뷰 1회차) 언어는 한국어. (가정) 단, 2회차 "됐다" 장면에는 답변 텍스트가 없고 상·중·하와 메모만 있다 → 도구에 답변을 받아 적어야 하는지는 미확인.
- 평가: 항목 3개(핵심 메시지 전달·부정적 표현 회피·답변 길이) × 상·중·하. 코치가 직접 매긴다. 도구는 판정 기준을 알 필요가 없다. (인터뷰 1·2회차) 평가 단위(질문마다 vs 연습마다)는 미확인 — 연습마다 한 번으로 가정. (가정)
- 메모: 구두로 전하던 말을 한 줄로. (인터뷰 2회차)
- 규모: 주 1회 × 선수 3~4명 × 질문 5개 = 연습 1회당 답변 15~20건. 시즌을 약 25주로 잡으면 시즌당 500건 이하. (수치는 1회차, 합산은 가정) 작다. 파일 저장으로 충분하다.
- 과거 기록: 종이 체크리스트가 쌓여 있다. 도구에 옮겨 넣어야 하는지는 미확인. (인터뷰 1회차, 2회차에 답 없음)

## 실행 환경 (런타임, 네트워크, 권한, 기존 시스템)
- 훈련장 노트북 한 대. 인터넷 된다. (인터뷰 1·2회차) OS·브라우저는 미확인.
- 외부 AI 서비스 호출 금지 — 아래 "금지·주의". 인터넷이 되더라도 처리는 노트북 안에서 끝낸다. (인터뷰 2회차)
- 기존 시스템 없음. 지금은 종이·녹음·홍보팀 엑셀(질문 목록)뿐. (인터뷰 1·2회차)

## 읽기/쓰기 특성 (동시 사용자, 쓰기 충돌 가능성)
- 코치 2명이 노트북 한 대를 같이 쓴다. 동시 사용자는 1명, 쓰기 충돌 없음, 다른 기기에서 볼 필요 없음 → 로컬 파일 저장으로 충분. (인터뷰 1·2회차)
- 두 코치 중 누가 매겼는지 기록에 남겨야 하는지는 미확인.

## 예외·엣지 케이스
- 선수 수 3~4명, 질문 수 "5개 정도"로 가변. 고정 개수로 짜면 안 된다. (인터뷰 1회차)
- 같은 선수가 반복 참여한다 — "지난 세 번 연습"이 전제. 비교 범위는 최근 3회. 3회 미만인 선수(첫 참여 등)는 있는 만큼만 보인다. (인터뷰 2회차, 마지막 문장은 가정)
- 받아 적지 못한 답변(녹음만 있는 경우)이 있을 수 있다. (1회차에서 추론)

## 금지·주의 (보안, 개인정보, 규정)
- 선수 이름이 들어가므로 외부 AI 서비스로 보내지 않는다. 담당자 명시. (인터뷰 2회차) → 자동 평가·AI 초안·외부 API 호출을 모두 뺀다.
- 선수 실명과 답변 내용은 구단 내부 자료. 노트북 밖으로 나가지 않는다. (인터뷰 2회차에서 확인)
