# GLOSSARY — 도메인 용어집

> 인터뷰에서 **확정된** 용어만 한 줄씩. 구현 세부사항은 쓰지 않는다. 코드·파일·API 이름은 **"코드 표기" 열**을 따른다(D-003) — 표에 없는 이름은 코드에 쓰지 않는다. 새 이름이 필요하면 여기부터 한 줄 추가한다.
> 한 단어가 두 뜻으로 쓰이면 두 용어로 나눈다. `/spec`이 추가한 용어는 "(/spec 가정)"으로 표시.

| 용어 | 뜻 (현업의 말로) | 코드 표기 | 유사어·주의 |
|---|---|---|---|
| 질문 목록 | 홍보팀이 엑셀로 관리하는 약 30개의 인터뷰 질문. 세트는 여기서 고른다 (인터뷰 2회차) | — (이번 범위 밖, P2) | 관리는 홍보팀, 고르는 것은 코치. 도구에 넣는 방법은 미확인 |
| 세트 | 코치가 그날 질문 목록에서 고른 질문 5개 정도. 선수 한 명이 연습 한 번에 받는 질문 묶음 (인터뷰 1·2회차) | — (P2) | 질문 묶음이지 답변 묶음이 아니다. 항상 정확히 5개는 아님. "그날 5개"라서 그날 선수 모두 같은 세트로 보임(가정) |
| 코치 | 연습을 진행하고 상·중·하를 직접 매기고 끝나면 구두로 알려주는 홍보팀 사람. 2명이 훈련장 노트북 한 대를 같이 쓴다 (인터뷰 1·2회차) | — (코드에 등장하지 않음. 누가 매겼는지 남기지 않음, 가정 A4) | 야구 코칭스태프가 아니라 홍보팀의 인터뷰 코치. 한 번에 조작하는 사람은 한 명 |
| 선수 | 인터뷰 연습을 받는 사람. 연습 한 번에 3~4명 (인터뷰 1회차) | `player` (이름 문자열이 곧 식별자, D-005) | 도구가 매긴 평가는 믿지 않는다 (2회차) |
| 연습 | 시즌 중 주 1회 하는 경기 후 기자 인터뷰 대비 연습 1회. "지난 세 번 연습"처럼 회차를 세는 단위 (인터뷰 1·2회차) | `date` (연습은 날짜로만 식별한다. 연습 객체는 없음) | 비교 범위는 최근 3회 |
| 체크리스트 | 코치가 연습 중 적는 평가표. 항목 3개 × 상·중·하 (인터뷰 1회차) | `items` | 지금은 종이 |
| 항목 | 체크리스트의 평가 기준 세 개: 핵심 메시지 전달 / 부정적 표현 회피 / 답변 길이 (인터뷰 1회차) | `key_message` / `avoid_negative` / `answer_length` | 이름은 확정. 판정 기준은 코치 머릿속이고 도구는 알 필요 없다 (2회차) |
| 상·중·하 | 항목별 3단계 평가. 코치가 직접 매긴다, 도구가 매기지 않는다 (인터뷰 1·2회차) | 값 `"상"` `"중"` `"하"` (한글 그대로 저장) | 숫자 점수로 바꿀지는 미확정 → 바꾸지 않는다. 질문마다인지 연습마다인지 미확정 → 연습마다 한 번으로 가정(A1) |
| 피드백 | 연습이 끝난 뒤 코치가 선수에게 **구두로** 알려주는 행위 (인터뷰 1·2회차) | — (구두 행위, 코드 없음) | 도구가 만드는 자동 평가가 아니다. 도구에 남기는 것은 '메모' |
| 메모 | 구두로 하던 피드백을 도구에 남기는 한 줄 (인터뷰 2회차) | `memo` | "한 줄이면 충분". 선수·연습 단위(=기록마다 하나)는 가정 |
| 비교 화면 | 선수 이름을 고르면 지난 세 번 연습의 항목별 상·중·하가 한 화면에 보이고 그 자리에서 오늘 것을 적는 화면. "하나만 된다면" 이것 (인터뷰 2회차) | `compare` (`GET /api/compare`, 화면 이름) | 비교와 입력이 한 화면 |
| 기록 (/spec 가정) | 선수 한 명의 연습 한 번에 대한 체크리스트(항목 3개 상·중·하)와 메모. 도구의 저장 단위. 선수×연습 날짜당 1건 | `record` (`PUT /api/records`, `data/records.json`) | 평가 단위가 연습마다 한 번이라는 가정(A1) 위에 있다. 틀리면 질문별 구조로 바뀐다 |
| 지난 세 번 (/spec 가정) | 비교 화면에서 보이는, 선택한 날짜보다 앞선 연습 최대 3회의 기록. 3회 미만이면 있는 만큼 | `previous` (비교 응답), 비교 범위 = 3 | "최근 3회"와 같은 말. 2회차 "지난 세 번 연습"에서 |
| 오늘 것 (/spec 가정) | 비교 화면에서 그 자리에서 적는, 선택한 날짜(기본 오늘)의 기록 | `today` (비교 응답) | 이미 있으면 입력란에 먼저 채워진다(D-004) |
