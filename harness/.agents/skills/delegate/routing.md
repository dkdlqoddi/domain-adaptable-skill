# 모델·문맥·재시도 예산

위임 전에 루트가 한 번 읽고 작업별로 선택한다. 모델을 불러 라우팅하지 않는다. 실행기의 `TIERS`가 기본값의 원본이며, 아래는 대회용 시작 정책이다. 실제 절감량은 검증된 결과와 관측 토큰으로 판단한다.

## 선택
| 대상 / `--tier` | 모델 | 추론 | 사용할 때 |
|---|---|---|---|
| 루트 | `gpt-6.1-sol` | low | 인터뷰·계약·브리프·통합. 어려운 결정만 medium/high |
| `implement` (기본) | `gpt-6-luna` | medium | 계약·샘플·쓰기 범위·검증이 정해진 작은 구현 |
| `light` | `gpt-6-luna` | low | 기계적 수정·명확한 추출. 도구 실행만이면 루트가 직접 |
| `reason` | `gpt-6.1-sol` | medium | 모호한 원인, 복잡한 알고리즘, 여러 모듈의 상호작용 |
| `fallback` | `gpt-6-sol` | medium | 주 모델 사용 불가 또는 해당 작업에서 검증한 대체 |
| `legacy` | `gpt-5.6-terra` | medium | 해당 작업에서 검증한 대체. 자동 승급 단계가 아님 |

- 작은 수정은 현재 루트에서 끝낸다. 모든 일을 작업자로 쪼개면 지침·브리프·보고 비용이 더 든다.
- 어려운 작업은 처음부터 `reason`. 단순한 작업은 `implement`, 같은 실패가 최소 수정 후 반복되면 멈춘다. 재현·실패 원인·현재 diff를 붙여 `reason`으로 **한 번만** 재위임한다. 그래도 실패하면 루트가 계약·범위·환경을 다시 확인한다. 인증·도구 오류는 모델을 바꿔 재시도하지 않는다.
- 모든 모델을 차례로 거치지 않는다. 하위 버전이라고 토큰 수·비용이 작다고 가정하지 않는다. 대회 과금 기준이 다르면 실제 완료당 사용량으로 선택을 조정한다.
- `--effort low|medium|high`는 이번 실행만 바꾼다. high는 어려운 추론에만 선택한다. `--model`은 모델만 바꾸고 tier의 effort를 유지하므로 둘을 확인한다.
- 순차 작업은 1개, 독립 범위가 확인되고 시간이 부족하면 2개 병렬. 3~6개는 넓은 독립 작업과 시간상 이득이 있을 때만. 같은 문제에 여러 모델을 동시에 붙여 비교하지 않는다.

## 전달과 보고
- 브리프는 대략 1화면(40줄 안팎): 목표·쓰기 범위·샘플·검증·금지사항·기존 변경. 계약 값과 실패 재현은 길이 때문에 생략하지 않는다.
- 관련 모듈 지침만 `--instruction`으로 준다. 루트 지침은 실행기가 중복을 피해서 처리한다. 전체 대화·SPEC·TASKS·스킬 본문·로그를 복사하지 않는다.
- 내장 서브에이전트 대체 시 새 문맥과 위 모델·effort를 지정한다. 지원하지 않는 모델은 임의 별칭으로 바꾸지 말고 루트가 직접 처리하거나 표의 사용 가능한 대체 모델을 고른다.
- 보고는 15줄 안팎: 상태·변경 파일·검증 명령/종료 코드/핵심 출력·알고리즘/경계 사례·BLOCKER/한계·근거 경로. 긴 로그는 파일에 두며 실패를 숨기지 않는다.
- 루트는 최종 diff·필수 검증으로 판정한다. 작업자의 모든 탐색을 되풀이하지 않는다. 동일 상태의 검증 명령은 통합 시 한 번씩만 실행한다.

## 관측
```bash
python3 .agents/skills/delegate/scripts/tmux_codex.py usage --project "$PWD"
```
- Codex는 `--json`의 `turn.completed.usage`를 `usage.json`에 기록한다. 입력·캐시 입력·출력과 `total_tokens`(입력+출력)를 보여 준다. 캐시 입력은 입력에 이미 포함되므로 다시 더하지 않는다.
- `usage`는 실패·재실행을 포함한 **모든 실행**을 모델/effort별 합산한다. `--id S1`은 해당 슬라이스의 모든 시도를 집계한다. 최신 실행만 보는 `status`와 다르다.
- `unknown_runs`와 `errors`를 함께 확인한다. 실행 중·강제 종료·누락된 이벤트는 0토큰이 아니며, 완료 턴만 관측하므로 실패 중 사용량은 빠질 수 있다. 다른 CLI와 루트 세션 사용량도 별도다. 총 대회 사용량·가격 추정치가 아니다.
- `prompt_bytes`는 전달한 브리프·지침 크기이며 자동 로드 지침과 도구 출력은 제외한다. 토큰 수로 환산해 실측처럼 보고하지 않는다.
