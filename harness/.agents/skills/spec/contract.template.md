# CONTRACT — 모듈 간 인터페이스 계약

> 모듈이 2개 이상일 때만 만든다(1개면 `SPEC.md` 8절). **루트 세션만 수정.** 모듈 작업 중 변경이 필요하면 멈추고 BLOCKER로 알린다.
> 프로젝트에 맞는 섹션만 남기고 나머지는 지운다. 섹션마다 **샘플 값 1개**를 반드시 적고 `fixtures/`에 파일로 둔다.

## 모듈과 경계
| 모듈(폴더) | 하는 일 | 입력 | 출력 |
|---|---|---|---|

## A. 공통 데이터 스키마
```
(JSON/YAML 스키마, dataclass, 타입 정의 — 샘플 값 포함)
```

## B. API (HTTP가 있을 때)
| Method | Path | 요청(샘플) | 응답(샘플) | 에러 |
|---|---|---|---|---|

## C. CLI (명령줄 도구가 있을 때)
| 명령 | 인자·플래그 | 표준출력(샘플) | 종료코드 |
|---|---|---|---|

## D. 파일 포맷 (파일로 주고받을 때)
| 파일 | 생산자 → 소비자 | 포맷·패턴 | 샘플 위치(fixtures/) |
|---|---|---|---|

## E. 상태 전이 (큐·파이프라인이 있을 때)
| 상태 | 전이 조건 | 다음 상태 | 실패 시 |
|---|---|---|---|
