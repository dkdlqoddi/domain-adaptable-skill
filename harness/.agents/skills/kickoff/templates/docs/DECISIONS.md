# DECISIONS — 결정 기록

> 결정이 생긴 명령이 그 자리에서 자동으로 덧붙인다. 직접 남기고 싶으면 "이 결정 기록해 줘"라고 말한다. 기존 항목은 고치지 않는다.
> 기록할 것: 사람이 고른 것, 실제 대안이 있던 선택, 되돌리기 비싼 선택, 거절·축소한 AI 제안("AI에 끌려가지 않았다"는 근거). 변수명 같은 것은 적지 않는다.
> 형식(한 건 3~5줄):
> `## D-NNN <제목, 8단어 이내>` / `- 상황:` / `- 선택:` / `- 대안과 기각 이유:` / `- AI 제안 여부: <없음 | AI가 X 제안 → 수용·축소·거절, 이유>`
