# TASKS — 작업 보드

> 슬라이스 = 끝까지 동작하는 가장 작은 기능 조각. P0부터. 상태: TODO / DOING / DONE / BLOCKED.
> 루트가 작업자 보고를 반영한다. 검증 명령이 없는 슬라이스는 시작하지 않는다. 시각은 한국 시각(`TZ=KST-9 date +%H:%M`)으로 적는다.

## 슬라이스
| ID | 슬라이스 | SPEC | 쓰기 범위(파일·폴더) | 선행 의존성 | 병렬 그룹 | 검증 명령·전용 자원 | 상태 | 담당(세션·보고 경로) |
|---|---|---|---|---|---|---|---|---|
| S0 | 걸어다니는 뼈대: 실행되고 입력 하나가 끝까지 지나간다 | - | | 없음 | 순차 | | TODO | |

> 병렬 그룹은 선행 의존성이 모두 DONE이고 쓰기 파일·검증 자원이 겹치지 않을 때만 실행한다. 공유 docs·Git은 루트 담당. 기본 2개, 최대 3개.
