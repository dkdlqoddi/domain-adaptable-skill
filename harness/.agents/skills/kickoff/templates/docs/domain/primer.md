# 사전 지식: 메모리 반도체 현장 (일반론)

> 공개된 일반 지식이다. SK하이닉스 내부 시스템 이름·용어·기준과 다를 수 있다.
> **질문의 재료로만 쓴다.** 현업이 확인한 것만 `workflow.md`·`constraints.md`·`GLOSSARY.md`로 옮기고 `(인터뷰 N회차)`를 단다. 확인 전에는 사실로 적지 않는다.
> 과제가 반도체 현장이 아니면 이 파일은 무시한다.

## 1. 물건이 흐르는 순서 (데이터가 생기는 곳)
1. **전공정(팹)**: 웨이퍼 위에 회로를 만든다. 증착·노광·식각·세정·이온주입·CMP를 수백 단계 반복한다.
2. **계측·검사**: 두께·선폭(CD)·오버레이를 재고, 결함을 찾아 좌표와 분류를 남긴다.
3. **웨이퍼 테스트(EDS)**: 칩(다이)마다 전기 테스트 → 양·불과 빈(bin) → 웨이퍼 맵과 수율.
4. **후공정**: 잘라서(다이싱) 패키지에 넣는다. HBM은 DRAM 다이를 TSV로 쌓는다.
5. **패키지 테스트**: 번인(가속 스트레스), 속도·등급 분류.
6. **품질**: 고객 불량 분석, 재발 방지 보고서.
- 설계·검증(회로 시뮬레이션, EDA 도구 리포트)과 사무(설비 보전, 생산 계획, 구매·품질 문서)도 현장이다.

## 2. 흔한 데이터 모양 (시스템 이름은 회사마다 다르다)
| 무엇 | 흔한 이름 | 모양 |
|---|---|---|
| 로트가 어느 공정·설비를 언제 지났나 | MES 이력 | 표: 로트 ID, 공정 단계, 설비·챔버 ID, 시각 |
| 설비 센서 값과 이상 감지 | FDC / EES | 시계열(초 단위), 설비·챔버·레시피별 |
| 계측값 관리 | SPC | 표 + 관리도(평균, 관리한계 UCL/LCL) |
| 수율·웨이퍼 맵 | YMS | 다이 좌표(x, y) + bin, 웨이퍼·로트별 수율 |
| 결함 | 검사 결과, ADC(자동 분류) | 좌표·크기·분류 + 이미지 |
| 설비 알람·정비 | 알람 로그, PM 이력 | 텍스트 로그, 다운타임 |
| 설계 검증 | 회귀 시뮬레이션 로그 | 텍스트 로그(리허설 2 과제) |

## 3. 현장이 자주 겪는 고민 (과제 후보)
- 수율이 떨어졌다 → 원인 공정·설비 찾기. 불량 웨이퍼들이 **공통으로 지난 설비·챔버**를 찾는 분석이 흔하다.
- 웨이퍼 맵 패턴 분류(가장자리 링, 중앙, 도넛, 스크래치, 국소, 랜덤). 패턴마다 의심 공정이 다르다.
- 설비 센서 이상을 사람보다 먼저 잡기, 알람 폭주 정리, 교대 인수인계 요약.
- 계측·검사 리포트, 불량 보고서 초안 작성, 과거 사례 찾기.

## 4. 헷갈리기 쉬운 단위와 기준
- 로트(보통 웨이퍼 25장) ⊃ 웨이퍼 ⊃ 다이(수백~수천 개). **"어느 단위로 보세요?"를 꼭 묻는다.**
- 설비 ⊃ 챔버(한 설비에 여러 챔버). 레시피 = 공정 조건 묶음.
- 수율 = 양품 다이 ÷ 전체 다이. 웨이퍼·로트·누적 수율이 다르다.
- 스펙(고객에게 약속한 규격) ≠ 관리한계(공정이 평소대로인지 보는 통계 기준). 넘었을 때 하는 일이 다르다.
- bin 번호의 뜻은 제품·테스트 프로그램마다 다르다. 표를 받아야 한다.

## 5. 제약·비목표의 단골
- 공정 조건·설계·수율 데이터는 핵심 기밀이다. 외부 AI·클라우드로 보내지 않는 것이 기본이다. 개발은 가짜 데이터나 마스킹한 데이터로 한다.
- 설비에 명령을 보내는 기능(쓰기·자동 조치)은 위험하다. 읽기 전용 분석이 기본이고, 쓰기는 비목표 후보다.
- 망 분리, 오래된 서버(구버전 Python, 패키지 설치 불가)가 흔하다. 실행 환경을 반드시 묻는다.

## 6. 질문 재료 (사다리 칸별, 현업의 말로 바꿔 쓴다)
- ① 그 일을 할 때 처음 여는 화면이나 파일은? 하루에 몇 번, 언제 보나?
- ② 불량·이상이 났을 때 원인 찾기에서 시간이 가장 오래 걸리는 단계는? 지난번에 놓친 것은?
- ③ 로트·웨이퍼·다이 중 어느 단위로 보나? 데이터는 어디서 꺼내고 하루에 몇 건인가? 밖으로 보내면 안 되는 데이터는? 보기만 하나, 설비에 무언가를 바꾸기도 하나?
- ④ "됐다"고 할 장면 하나만. 그 결과를 누구에게 보여 주나?
- ⑤ "A→B→C로 보고, 설비 자동 조치는 이번에 빼려는데 맞나요?"

## 7. 용어 (일반 뜻 — GLOSSARY에는 현업 확인 후에만 넣는다)
| 용어 | 일반 뜻 |
|---|---|
| 팹(FAB) / 전공정 / 후공정 | 웨이퍼 제조 공장 / 웨이퍼 위 회로 제작 / 자르고 패키지·테스트 |
| 로트, 웨이퍼, 다이 | 함께 흐르는 묶음 / 원판 / 웨이퍼 위 칩 하나 |
| 수율, 빈(bin), 웨이퍼 맵 | 양품 비율 / 테스트 결과 분류 번호 / 다이 좌표별 양·불 지도 |
| CD, 오버레이 | 선폭 / 층 사이 정렬 오차 |
| 레시피, PM | 설비의 공정 조건 묶음 / 예방 정비 |
| 익스커션(excursion) | 공정이 평소 범위를 벗어난 사건 |
| EDS | 웨이퍼 상태에서 칩마다 하는 전기 테스트 |
| DRAM, NAND, HBM, TSV | 휘발성 메모리 / 비휘발성 플래시 / DRAM을 쌓은 고대역폭 메모리 / 다이를 관통하는 전극 |
