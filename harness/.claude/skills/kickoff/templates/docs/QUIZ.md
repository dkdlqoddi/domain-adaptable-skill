# QUIZ — 상황 적용과 설계 설명

> 기본 12문항, 마무리 16문항. 4문항씩 풀며 적어도 절반은 서술·계산·추적이다. 문제별 2점.
> 정답은 QUIZ-ANSWERS.md에서 답을 제출한 뒤 확인한다. 퀴즈는 제출 관문이 아니다.

## 회차·범위
회차 ID, 작성/개정 시점, 설계/구현 범위, 근거 버전·코드·테스트 위치. 이미 푼 회차의 문제·답·점수는 보존하고, 변경 시 새 회차·개정으로 연결한다.

## 전체 내용과 문항 연결
마무리에는 KNOWLEDGE 0절의 일곱 주제와 SPEC의 모든 P0를 연결한다. 범위표에는 정답·결론을 적지 않는다.

| 주제 / P0·결정 ID | KNOWLEDGE 절·근거 위치 | 회차·Q-ID | 확인 상태 |
|---|---|---|---|

확인 상태: 미응답 / 보충 필요 / 설명 확인. 한 문제에 여러 주제를 연결할 수 있다.

## 문제
문항마다 Q-ID, 범주, 난도, 평가할 능력, 입력·가정, 질문, 배점을 적는다. 정답·힌트는 넣지 않는다.
마무리 마지막 문항은 전체 흐름·선택·검증·한계를 자기 말로 설명하고, 달라진 조건에 적용하는 문제다(16문항에 포함).

## 진행·복습
답한/전체 문항 수, 다음 Q-ID, 미응답·건너뛴 문항, 약점, 재학습할 KNOWLEDGE 절·코드 위치와 다음 행동. 답·상세 채점은 해설 파일에 기록한다.
미응답은 0점으로 처리하지 않는다. 중단·재개 시 기존 진행 위치를 남긴다.
