# DECISIONS — 결정 기록

> 되돌리기 비싸거나, 나중에 보면 의아하거나, 실제 대안이 있었던 결정만. 한 건 3~5줄. `/decide`로 덧붙인다.
> 거절·축소한 AI 제안도 기록한다. 이것이 "AI에 끌려가지 않았다"는 근거다.

## D-000 형식 예시 — 첫 실제 결정을 적을 때 이 항목은 지운다
- 상황: 코칭 기록을 어디에 저장할지
- 선택: 로컬 JSON 파일 1개
- 대안과 기각 이유: SQLite(동시 쓰기 없음, 설정 비용), Postgres(환경 없음)
- AI 제안 여부: AI가 ORM+마이그레이션 제안 → 거절. SPEC 비목표(다중 사용자) 해당
