# /decide — 결정 3줄 기록

## 왜
사후 Q&A와 면접은 "왜 이 구조인가, 어떤 대안을 왜 버렸나, AI의 어떤 제안을 왜 거절했나"를 묻는다.
기억에 기대지 않도록 결정한 순간에 적는다. 적을 가치가 있는 결정은 셋 중 하나다:
되돌리기 비싸다 · 나중에 보면 의아하다 · 실제 대안이 있었다. 변수명 같은 것은 적지 않는다.

## 절차
1. `docs/DECISIONS.md` 마지막 번호를 보고 다음 번호 `D-NNN`을 붙인다. (`grep -o 'D-[0-9]*' docs/DECISIONS.md | tail -1`)
2. `$ARGUMENTS`에서 상황·선택·이유를 뽑는다. **대안** 또는 **AI 제안 여부**가 빠졌으면 둘 중 하나만 한 번 묻는다(추천 답 포함). 유추 가능하면 유추하고 `(추정)` 표시. 단, AI 제안 여부는 이 세션에 근거가 없으면 추천 답 없이 묻는다. 앞 세션의 AI가 제안했을 수 있다.
3. 아래 형식으로 파일 끝에 **덧붙인다**. 기존 항목은 고치지 않는다. 단, 템플릿의 `D-000 형식 예시` 항목이 남아 있으면 이번에 지운다.

```
## D-NNN <제목, 8단어 이내>
- 상황: <무엇을 정해야 했나>
- 선택: <무엇을 택했나>
- 대안과 기각 이유: <대안 1~2개, 각각 왜 아닌가>
- AI 제안 여부: <없음 | AI가 X 제안 → 수용/축소/거절, 이유>
```

4. 계약이 바뀌는 결정이면 `docs/CONTRACT.md` 변경 이력에도 번호를 적는다.
5. 출력: 추가한 항목만 그대로 보여준다. 다른 말은 덧붙이지 않는다.
